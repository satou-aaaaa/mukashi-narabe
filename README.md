# 昔話ならべ

ばらばらになった日本の昔話の場面を、お話の順に並べるあそびです。知らないお話でも、「〜したから、〜になった」というつながりを考えれば並べられます。だれでも同じ1日3話、練習・とことんは何度でも。

- 遊ぶ: <https://satou-aaaaa.github.io/mukashi-narabe/>
- 次に起きることのカードを押していくと、上の絵巻に順に書かれます。順がちがうカードを押しても、もう一度選べます。
- ヒントを押すと、次のカードに 👉 が付きます。3回続けてまちがえても 👉 が付きます（行き止まりになりません）。まちがいもヒントもなしで★3つ。
- 並べ終えると、お話の全部の場面と「このお話から」（教え）が出ます。青空文庫で読めるお話には、そのリンクも出ます。
- 今日の3話（カード4・5・6枚、はじめの場面は見せる）と上級（はじめの場面も並べる7枚×2話・ヒントなし）はだれでも同じで1日1回。とことん（一度で何話並べられるか。カードは4枚から7枚へふえる）・練習（お話を選んで並べる）は何度でも。
- 出会ったお話は「お話帳」に集まり、いつでも全部の場面を読めます。実績・カレンダー（7日前まであとから遊べる）もあります。時間制限はありません。
- お話は32話。各7場面（あとから足した5話は練習・とことん・お話帳で出会えます）。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（お話の名前や場面は入りません）。

## お話の出どころ

- どのお話も、昔から語りつがれ、だれのものでもない日本の昔話です。場面は、広く知られた筋をもとに、短い言葉で書き直しました（文はこのゲームのために書いたもの）。土地や本によって筋がちがうお話もあります。
- 筋は、青空文庫で読める楠山正雄（1884–1950）の再話などを手がかりにしました。楠山正雄の作品は著作権の保護期間が終わっています（[青空文庫 作家別作品リスト：楠山正雄](https://www.aozora.gr.jp/index_pages/person329.html)）。
- 小学校の国語では、1・2年で「昔話や神話・伝承などの読み聞かせを聞くなどして、我が国の伝統的な言語文化に親しむこと」と、物語の「場面の様子や登場人物の行動など、内容の大体を捉えること」を学びます（[文部科学省 小学校学習指導要領 国語](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/syo/koku.htm)）。このゲームは、場面の順を考えて筋をつかむ練習の形です。
- 神話・妖怪のお話は入れていません（別のゲームで扱います）。
- まちがいを見つけたら、[感想のフォーム](https://github.com/satou-aaaaa/mukashi-narabe/issues/new?template=feedback.yml)で教えてください。
